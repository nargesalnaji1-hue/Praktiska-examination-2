# Praktiska-examination-2
Konsolbaserad Socket.IO-chatklient i C# (YH IT-systemutvecklare)
Detta projekt är ett .NET Web API som använder Entity Framework Core och SQLite för att hantera data, relationer och seedning av databasen. Projektet är uppbyggt med en tydlig struktur där Models, Controllers, Data och Migrations samverkar för att skapa ett komplett API med full CRUD‑funktionalitet. För att köra projektet börjar man med att installera alla beroenden genom att köra dotnet restore. Därefter körs dotnet ef database update, vilket automatiskt skapar SQLite‑databasen och applicerar alla migrationer samt lägger in seed‑data. Seedningen innehåller fördefinierade Authors och Books som gör att API:t kan testas direkt utan att man behöver skapa data manuellt. När databasen är skapad startas API:t med dotnet run, vilket gör att servern startar och Swagger blir tillgängligt på /swagger där alla endpoints kan testas visuellt. API:t innehåller endpoints för att hämta, skapa, uppdatera och ta bort både Authors och Books, och relationen mellan dem hanteras av EF Core. För att underlätta testning finns även en Postman‑collection (postman_collection.json) inkluderad i projektet. Den kan importeras direkt i Postman och innehåller färdiga anrop för GET, POST, PUT och DELETE för båda entiteterna, vilket gör det enkelt att verifiera funktionaliteten och se hur API:t svarar. Denna README beskriver hur projektet installeras, körs, seedas och testas, hur databasen skapas och hur Postman‑filen används. Texten uppfyller lärarens krav på tydliga körinstruktioner och dokumentation som visar hur projektet fungerar i praktiken.
